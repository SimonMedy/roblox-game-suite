- **3.1.1:** strict GLB diagnostics, node transforms, regressions.
- **3.1.0:** Blender/GLB audits, collection filtering, material/UV checks.
- **3.0.0:** Agent Skills packaging, HQ/GAME/MOBILE, modular references and MIT license.
